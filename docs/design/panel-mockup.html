电池警示条 · 细部与变体

SPEC §8（D5：不静默降级）

核心原则：电池下不静默降级，提示后由用户决定。主形态见上节 C 面板；此处拆解按钮语义，并补两个相邻变体（低电量拒绝、外部接管提示，后者属 SPEC §9，仅示意）。

当前使用电池。合盖不睡约每小时耗电 8–12%，且合盖散热受限。

继续 改用防空闲 取消
按钮语义
  • 继续：坚持开合盖档，明知耗电
  • 改用防空闲：改切防空闲档（合盖需求放弃，任务不断）
  • 取消：不开，维持原档
  • 勾选默认不勾——每次都问是刻意的（SPEC §8「默认不记住」）

电量 14%，低于安全阈值 20%。已拒绝开启合盖不睡。

改用防空闲 取消
变体一：电量低于阈值（默认 20%）
  • 直接拒绝，不提供「继续」（SPEC §8）
  • 出现在同一位置，红色系与橙色警示区分「可自担风险 / 不可」

当前由 Amphetamine 控制电源管理，NightCat 的档位未生效。

变体二：外部接管提示（SPEC §9，示意）
  • 中性信息条，不带操作按钮——规格只要求「明确显示」，交互未定
  • 出现在状态行下方、档位控件上方

未定项 · 请批注

SPEC §11 + 本稿新增判断
  1. 档位四色未定稿——现为讨论稿参考值（dark mode）；浅色模式下需整套重校（本稿第 4 节仅示意，青/橙原值在白底偏浅）。
  2. 锁标形态未出图——本稿用「档位同色小锁 + 深色底衬」示意，具体形状（实心/描边、底衬是否保留）待定。
  3. 倒计时文本格式——本稿用 58:12 / 1:23:45；是否改用「58 分」等本地化格式待定。
  4. 主按钮 / 点亮锁标的强调色——现用系统蓝 #0A84FF，与「屏幕常亮蓝 #85B7EB」不同但相近，是否冲突待你判断。
  5. 定时器默认档「不限时」为新增设计判断（SPEC §7 只列 15/30/60/120 + 自定义），请确认。
  6. 分段控件短名（常亮 / 合盖）与状态行的一句话语义描述为本稿拟定，待确认。
  7. 警示辅助色（低电量红 #E5524A、充电黄 #F0C75E）为本稿新增建议，规格未涉及。
  8. 外部接管提示（SPEC §9）仅画了信息条示意，完整状态与交互不在本稿范围。
  9. 工程内部重命名（target / 目录）仍按 SPEC §11 延后，与本稿无关。
